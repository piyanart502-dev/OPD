# ระบบบันทึกโภชนบำบัดผู้ป่วยนอก

แอปบันทึกการให้โภชนบำบัดผู้ป่วยนอก กลุ่มงานโภชนศาสตร์ โรงพยาบาลเจริญศิลป์

- `index.html` — ตัวแอป (ไฟล์เดียว)
- `icons/` — ไอคอนแอป
- `manifest.webmanifest` — ให้ติดตั้งลงหน้าจอโฮมได้

> ข้อมูลผู้ป่วยถูกเก็บในเบราว์เซอร์ของเครื่องที่ใช้งานเท่านั้น (ไม่อัปโหลดขึ้น GitHub)
